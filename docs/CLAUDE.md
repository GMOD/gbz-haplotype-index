# Writing docs

Before you write or edit a page in this folder, read the anti-AI writing tropes
skill at `~/src/claudish/skills/anti-ai-writing-tropes/SKILL.md`. Run the
`scan.sh` beside it on every file you change, including the `.dot` and
hand-written `.svg` files in `img/`, since diagram labels follow the same rules
as prose.

Call a query that sets `keep` "a query that uses the `keep` option". For
example, "A query with `keep` takes the anchored route" becomes "A query that
uses the `keep` option takes the anchored route".
